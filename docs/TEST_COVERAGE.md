Additional Phase 1 tests cover credential/token column permissions, inability to SET ROLE to authentication authority, forged user IDs, CSRF/origin failures, oversized streamed JSON bodies, strict role fields, audit UPDATE/DELETE/TRUNCATE rejection, session idle/absolute expiry and authorization-version mismatch, required password changes, disabled accounts, concurrent duplicate rates, schedule day ownership, overnight policy defaults, and the exact twelve-table migration boundary.

Tests append randomly named records to the dedicated test database. Browser evidence uses fake test identities; screenshots are not live workforce data. Fixture credentials are not used by production or dev-seeded users.
